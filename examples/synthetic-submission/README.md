# Synthetic AIDaR submission

This project is a test artifact. It does not report real research.

The draft studies a synthetic data-readiness score. The project uses a small
table, one analysis script, a manuscript source file, and a PDF. This layout is
only an example. AIDaR does not require these names or directories.
