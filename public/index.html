Git history, workflow files, and the local AIDaR identity file are excluded. Individual files are limited to 25 MB; browser uploads are limited to 100 MB total.

About

AIDaRS is the reviewer-anonymous submission and review system for the NeurIPS 2026 AI Data Readiness (AIDaR) Workshop in Paris. We use it to test whether scientific work can be organized for both people and AI agents during peer review. Authors can expect local privacy checks, no retained project files on this server, versioned feedback on GitHub, and the ability to read and answer reviews with the aidar tool; workshop organizers and GitHub remain inside the trust boundary.
